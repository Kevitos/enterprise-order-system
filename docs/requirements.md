# Enterprise Order System

## Objective

Develop an enterprise-grade Order Management System to simulate a real-world corporate backend application.

The project aims to demonstrate modern Java backend development practices, including layered architecture, REST APIs, automated testing, CI/CD, database versioning, and integration with legacy systems.

---

# Business Context

Enterprise Order Ltd. sells electronic products to corporate customers.

The company needs a system capable of managing:

- Customers
- Products
- Orders
- Inventory
- Payments

The application will also integrate with a legacy SOAP service responsible for invoice generation.
